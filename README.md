# Agent
1. 项目解决的核心痛点  我构建了一个面向代码库维护和技术债治理的 AI Agent，主要解决大型项目中技术债难以及时发现、人工 Code Review 重复成本高、安全风险容易遗漏的问题。  在实际开发中，代码库里常见的 TODO/FIXME 遗留、重复代码、过长函数、深层嵌套、调试输出残留、宽泛异常捕获、硬编码密钥等问题，往往分散在不同模块中，单靠人工 Review 很难持续发现。这个 Agent 可以自动扫描代码库，识别高风险问题，并根据严重程度和文件变更频率生成风险排序，帮助团队优先处理最需要治理的模块。  2. 核心逻辑流  该项目采用“规则初筛 + LLM 深度复核 + 报告生成 + CI 拦截”的分层 Agent 流程。
